<h2>📋 О проекте</h2>

Полнофункциональное веб-приложение для работы с картотекой граждан, включающее:

📊 Интерактивный дашборд с аналитикой и графиками

👥 Таблицу граждан с расширенной фильтрацией и поиском

👤 Детальные карточки с полной информацией о гражданах

Приложение демонстрирует современный подход к разработке интерфейсов и полностью соответствует требованиям тестового задания.

<h2>🎯 Основной функционал</h2>

<b>Дашборд:</b> Визуализация статистики

<b>Таблица граждан:</b> Пагинация для работы с большими объемами данных

Расширенная фильтрация по всем полям

Поиск по ФИО и другим параметрам

Сортировка по колонкам

Карточка гражданина:

<b>Вкладки:</b> Личная информация, Рабочая информация, Контакты, Дополнительно

Валидация форм

<h2>🛠 Технические преимущества</h2>

<b>Производительность:</b> Оптимизированная работа с большими данными

<b>Масштабируемость:</b> Модульная архитектура компонентов

<b>UX/UI:</b> Современный интерфейс

<b>Код</b>: Чистая, поддерживаемая кодовая база

<h2>Установка и запуск</h2>

Клонируйте репозиторий

```bash
git clone https://github.com/Knyaz3z/test_npc_irs.git
```
```bash
cd test_npc_irs
```
Установите зависимости

```bash
npm install
```
Запустите приложение

```bash
npm run dev
```
Откройте в браузере

```text
http://localhost:3000
```
Сборка для production

```bash
npm run build
```

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
